    <div className="ds-grid">

        <h4>Typography Classes</h4>
        <p>Apply pre-registered typography rules directly by adding their class names:</p>
        <pre><code>{`<h1 className="heading-heading-1">Page Title</h1>
<p className="body-large-regular">Body text</p>`}</code></pre>
      </div>
    </div>
  </div>

  <div className="ds-section">
    <h2>Headless Components (Base UI)</h2>
    <p>We use <strong>Base UI</strong> (<code>@base-ui/react</code>) as our foundation to ensure fully accessible, WAI-ARIA compliant components. These are styled using our design system variables.</p>
    
    <h3>Example: Button Component</h3>
    <p>The Button supports multiple sizes, variants, and semantic modes (primary, tertiary, and destructive):</p>
    <pre><code>{`import { Button } from '@padi/design-system';

export default function App() {
  return (
    <Button variant="solid" size="medium" mode="primary">
      Primary Action
    </Button>
  );
}`}</code></pre>
  </div>

  <div className="ds-section">
    <h2>Theme & Mode Switching</h2>
    <p>Functional collections (like button states or anchor text) leverage Figma multi-mode variables. The correct colors are resolved using <code>[data-mode-*]</code> selectors on the component or a parent wrapper.</p>
    <pre><code>{`/* Toggling button mode to destructive */
<Button mode="destructive">Delete Item</Button>

/* In CSS, this resolves variables using: */
[data-mode-button="destructive"] {
  --state-default: var(--red-500);
  --state-hover: var(--red-600);
  ...
}`}</code></pre>
  </div>
</div>
